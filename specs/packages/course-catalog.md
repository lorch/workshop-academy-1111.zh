# course-catalog: 课程目录与详情

## 意图

本规约包使访客与登录学员能够按统一的可见性规则浏览课程目录与课程详情。
它规定课程对外的可见范围、公开字段、页面呈现与封面，不规定报名管理、观看资格与课程管理接口。
它依据 [DR-001](../decisions/001-enrollment-mvp.md) 的 D2 与业务边界 3 保留本轮不改变的公开浏览行为。

## 外部行为

### catalog-1

当请求 `GET /api/courses`，课程目录接口应以 JSON 返回按编号升序排列的全部已发布课程：

| 情形 | 结果 |
| --- | --- |
| 课程已发布 | 出现在 `courses` 数组中 |
| 课程为草稿 | 不出现在 `courses` 数组中 |

- 每个课程对象的字段集合为 `id`、`title`、`summary`、`description`、`instructor`、`level`、`levelLabel`、`durationSeconds`、`published`、`url`、`coverUrl`、`updatedAt`。
- 课程对象不包含 `videoFile`、`createdAt` 等仅管理员可见的字段。

### catalog-2

当请求 `GET /api/courses/:id`，课程详情接口应仅返回已发布课程的公开字段，且对草稿、不存在或编号不合法的课程返回 404 与中文 JSON 错误：

- 未发布课程与不存在的课程对外一视同仁，错误消息相同。
- 编号不合法包含非正整数、前导零与无法解析为编号的值。

### catalog-3

当访客或已登录学员请求 `GET /` 或 `GET /courses/:id`，站点应无需登录返回带站点外壳的中文 HTML 页面：

- 目录页列出全部已发布课程并链接到各课程详情页。
- 详情页展示课程标题、简介、介绍、讲师、难度、时长、更新时间与封面。
- 草稿、不存在或编号不合法的课程详情页返回 HTML 404 页面，而非 JSON。
- 课程标题、简介等文本经转义后渲染，其中包含的标记不会作为脚本执行。

### catalog-4

给定学堂启用报名能力 [DR-001](../decisions/001-enrollment-mvp.md)，当访客或学员在报名前、持有效报名或已取消报名后浏览课程目录与课程详情，站点应返回相同的课程集合与课程详情，且不以登录状态、报名状态 [[enrollment-2](course-enrollment.md#enrollment-2)] 或观看资格过滤课程：

| 浏览者状态 | 目录与详情 |
| --- | --- |
| 访客 | 与已登录学员相同的课程集合 |
| 已登录但无报名 | 与访客相同的课程集合 |
| 持有效报名 | 与报名前相同的课程集合 |
| 报名已取消 | 与报名前相同的课程集合 |

### catalog-5

当请求 `GET /covers/:id.svg`，站点应按课程编号返回像素风格 SVG 封面：

- 同一编号重复请求返回相同内容，不同编号返回不同内容。
- 编号不合法时返回 404。
- 响应带 `public` 缓存策略，且草稿课程也可显示封面。

## 验证

### catalog-6

给定真实服务与临时数据库已启动，当请求 `GET /api/courses` 并分别请求已发布、草稿、不存在与编号不合法的课程详情，集成验证应断言课程列表仅含按编号升序排列的已发布课程、字段集合不含管理字段 [[catalog-1](#catalog-1)]，并断言草稿、不存在与编号不合法的详情均返回 404 与中文 JSON 错误 [[catalog-2](#catalog-2)]。

### catalog-7

给定真实服务与临时数据库已启动，当以访客身份请求目录页、已发布课程详情页与草稿课程详情页，系统验证应断言无需登录即可获得中文 HTML、课程信息与封面完整呈现、页面文本被转义、草稿详情页返回 HTML 404 页面 [[catalog-3](#catalog-3)]。

### catalog-8

给定真实服务与临时数据库已启动，当同一学员在报名前、报名成功后与取消报名后分别请求课程目录接口、课程详情接口及对应页面，系统验证应断言三次返回的课程集合、课程详情与页面内容一致，且不因登录状态、报名状态或观看资格改变可见性或排序 [[catalog-4](#catalog-4)]。

### catalog-9

给定真实服务已启动，当连续请求同一编号封面、不同编号封面与非法编号封面，集成验证应断言响应为 SVG 且带 `public` 缓存策略、同一编号内容一致、不同编号内容不同、非法编号返回 404 [[catalog-5](#catalog-5)]。
