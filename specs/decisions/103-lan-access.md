# DR-003: 局域网访问作为显式开关

## 状态

已接受（2026-11-11，随本次实现记录）

## 背景

- 服务默认只监听 `127.0.0.1`，并只放行 `localhost`、`127.0.0.1`、`[::1]` 三个 `Host` 值。
- 示例账号使用公开密码，服务没有 TLS、没有速率限制，也没有面向公网部署的认证改造。
- 课堂演示需要同一局域网内的其他设备访问同一份运行中的数据。
- 仅本机监听是有意的安全边界，不应因一次演示而被无声改变。
- 本记录遵循 [DR-000](000-spec-structure-format.md) 规定的 ADR 格式与组织约定。

## 决策

| 编号 | 决定 |
| --- | --- |
| D1 | 默认监听地址与默认 `Host` 允许列表保持不变 |
| D2 | 由显式的通配监听地址开启局域网访问；省略该配置即回到仅本机模式 |
| D3 | 局域网模式只额外放行启动时枚举到的本机网卡地址，不取消 `Host` 校验 |
| D4 | 自定义 `.local` 名称与端口转发域名只能显式列入允许列表，不自动信任任意主机名 |
| D5 | `Origin` 同源校验、会话 cookie 与播放地址签发逻辑保持不变 |
| D6 | 启动日志给出可分享的局域网地址，运行记录仍写本机可连的地址 |

## 影响

- 未开启局域网访问时，外部设备无法连接，现有部署与集成测试无需改动。
- 开启后，同网段所有人都能访问示例账号、管理后台与数据库内容；只在可信网络临时开放。
- 运维说明、HTTP 接口约定与 README 需同步说明开关、允许列表及风险。
- 集成测试需覆盖：默认模式拒绝局域网 `Host`、局域网模式放行本机网卡地址与显式主机名、陌生 `Host` 仍返回 400。
- 本轮不引入 TLS、账号体系改造、访问控制列表或反向代理配置。
